## 2. ANALYSE ET CONCEPTION (25-30 pages)

### 2.1 Architecture générale (4-5 pages)

- **Schéma d'architecture** : Frontend React / Backend Node.js / Base PostgreSQL
- **Organisation en repositories séparés** :
  - **Repository Frontend** : Application React standalone
  - **Repository Backend** : API REST Node.js/Express
  - **Avantages** : déploiement indépendant, équipes spécialisées, scalabilité
- **Choix technologiques justifiés** :
  - Frontend : React 19, Vite, TailwindCSS, TanStack Query
  - Backend : Node.js, Express, TypeScript, Sequelize
  - Base de données : PostgreSQL
  - Outils : Docker, npm/pnpm

### 2.2 Modélisation de la base de données (8-10 pages)

- **MCD** (Modèle Conceptuel de Données)
- **MPD** (Modèle Physique de Données) avec types PostgreSQL
- **Tables principales** :
  - `users` : profils utilisateurs
  - `skills` : compétences disponibles
  - `user_has_skills` : association many-to-many
  - `services` : demandes/offres de services
  - `messages` : système de messagerie
  - `reviews` : évaluations des services
  - `roles` : gestion des permissions
- **Scripts de création** et de seeding

### 2.3 Architecture backend (6-8 pages)

- **Repository Backend** - Structure indépendante :
  - **Structure MVC adaptée** :
    - Models (Sequelize) : User, Skill, Service, Message, Review, Role
    - Controllers : auth, user, skill, service, message
    - Routers : organisation des endpoints REST
  - **Middlewares** :
    - Authentification JWT
    - Validation des données (Zod schemas)
    - Sécurité (CORS, protection XSS)
  - **Configuration** : variables d'environnement, base de données
- **API REST** : documentation des endpoints principaux

### 2.4 Architecture frontend (6-8 pages)

- **Repository Frontend** - Application React autonome :
  - **Structure React/Vite** :
    - Pages principales : Home, Register, Profile, Search, Messages
    - Composants réutilisables et hiérarchie
    - Hooks personnalisés pour la logique métier
  - **Gestion d'état** : TanStack Query pour le cache et les requêtes API
  - **Routing** : React Router DOM pour la navigation SPA
  - **UI/UX** : TailwindCSS, composants Radix UI, design responsive
- **Communication API** : configuration Axios, gestion des erreurs
